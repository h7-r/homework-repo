# 📚 Frontend Homework Archive

프론트엔드 학습 과정에서 진행한 **일일 과제와 실습**을 날짜별로 정리한 저장소입니다.

<br/>

## 📌 소개

이스트캠프 오르미 프론트엔드 11기 과정 중, 매일의 강의 내용을 직접 손으로 구현하며
**HTML · CSS · JavaScript** 기초를 다진 기록입니다.

<br/>

## 🗂️ 구조

날짜(`YYYY-MM-DD`) 폴더 단위로 그날의 과제를 정리했습니다.

```
homework-repo/
├── 2025-12-22/   # 폴더·HTML 생성 및 첫 과제
├── 2025-12-23/   # 일일 과제
├── 2025-12-24/   # 일일 과제
├── 2026-01-06/   # 일일 과제
└── ...           # 날짜별 일일 과제 계속
```

<br/>

## 🛠️ 사용 기술

`HTML` · `CSS` · `JavaScript`
